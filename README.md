# My Keyboard is Full of Ants!

This is the Github repository for _My Keyboard is Full of Ants!_, a Ludum Dare 56 game! This game won 1st place overall, 2nd place in humor, 2nd place in theme, and 2nd place in fun.

You can download the game for free from [Itch.io](https://plasmastarfish.itch.io/my-keyboard-is-full-of-ants).
